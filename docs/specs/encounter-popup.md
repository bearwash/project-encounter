# Encounter Popup — 公園の入口での対面挨拶シーン

> 関連: [要件定義 §3.1, §3.2 A, §4.3](../要件定義.md) / [ble-handshake.md](ble-handshake.md) / [encounter-plaza.md](encounter-plaza.md) / [avatar.md](avatar.md)

## 1. ゴール (What & Why)
バックグラウンドでサイレントに蓄積されたすれ違いデータを、アプリを開いた瞬間に「サプライズ」として一気に開示する。
**舞台は公園の入口（ゲートの前）**。隊列で並んで歩いてきたアバターたちが、1 人ずつユーザー自身のアバターと対面し、ハイタッチ（複数回会った相手）または会釈（初回）して挨拶を交わす。全員終わると、ユーザーのアバターも合流して全員でゲートをくぐり広場へ入っていく。

3DS『すれちがい Mii 広場』の挨拶シーンの体験的核（「入口でひとりずつ出迎える」「ハイタッチで再会を喜ぶ」「メッセージを交わす」）を、独自のフラットベクター人型キャラと「夕方の公園」の世界観で再構築する。

## 2. ユーザーストーリー
- ユーザーとして、しばらくぶりにアプリを開いたとき、その間にすれ違った全員と「公園の入口」で順番に挨拶したい。
- ユーザーとして、何回か会ってる相手とは「ハイタッチ」して再会感を味わいたい。
- ユーザーとして、何人と会ったかが上部のストリップ UI で一目で分かってほしい。
- ユーザーとして、興味がない相手はサッとタップで飛ばしたい。
- ユーザーとして、全員と挨拶した後は、皆と一緒にゲートをくぐって広場に入っていく実感がほしい。

## 3. スコープ
### In Scope
- 公園の入口（ゲート前）を舞台にした対面シーン
- ユーザー自身のアバター（左）と相手アバター（右）の **斜め内向き 2 ショット構図**
- 隊列で並んで入場してくる演出（次に挨拶する相手が画面奥に並んで見える）
- ハイタッチ動作（**2 回目以降の相手のみ**。初回は会釈）
- 「TAP!」小エフェクト（ハイタッチ成立時）
- メッセージ吹き出し表示（システムプレフィックス + 本人メッセージ）
- 上部ストリップ UI に「今日のすれ違い：N 人」表示
- **1 セッション最大 20 人** までで一旦区切る（残数があれば「会いにいく」ボタン）
- 「会いにいく」ボタンで次の 20 人を続けて表示
- 既読化（表示済みレコードを `is_read = true` に）
- 全員終了後、カメラパン + 全員でゲート通過 → 広場ビューへ遷移
- 0 件のときは表示しない（直接広場ビューへ）

### Out of Scope
- プッシュ通知（OS 通知）
- ポップアップからのチャット・フォロー等の関係性アクション（後フェーズ）
- アバターの 3D アニメーション（[要件定義 §7 Phase 2](../要件定義.md)）
- 自分の Mii / アバターの編集（[profile.md](profile.md) で別途）

## 4. 画面構成

### 4.1 全体レイアウト

```
┌──────────────────────────────────────┐
│  ── 今日のすれ違い：5 人 ──           │ ← 上部ストリップ UI
│                                      │
│        ＿＿                          │
│       /    \  ← ゲート（門）の       │
│       | 門 |     シルエット          │
│       |    |                         │
│                                      │
│         ↘  ↙       👥👥👥           │ ← 次に並ぶ隊列
│       😊  🙂       （画面奥、小さく） │
│        │   │                         │
│       足  足   ← 自分(左) / 相手(右) │
│   ──────────       両者斜め内向き    │
│                                      │
│  ┌──────────────────────┐            │
│  │ やっと 3 回目！         │ ← 吹き出し │
│  │ 最近は Rust 勉強中！    │            │
│  └──────────────────────┘            │
│                                      │
│                       [タップで次へ] │
└──────────────────────────────────────┘
```

### 4.2 構図の詳細
- **カメラ位置**: ゲートの斜め手前。やや低めから 2 人の上半身が大きく見える。
- **自分のアバター**: 画面の **左寄り中央**。**右斜め内向き 30°**（カメラに対し顔が見える角度）。
- **相手のアバター**: 画面の **右寄り中央**。**左斜め内向き 30°**。
- **隊列**: 画面の **右奥**（ゲートの右側）に、次に挨拶する相手が **2〜3 人小さく重なって** 並ぶ。先頭が次のターン、その後ろがさらに次。20 人並ぶ場合でも視覚上は 3 人くらいで省略表現。
- **背景**: 公園の入口ゲート（門）。広場ビューと同じ世界観・配色。
- **上部ストリップ**: 半透明の角丸バー。「今日のすれ違い：N 人」「{現在 i} / {総数 N}」の小さなインジケータ。

### 4.3 ストリップ UI
- 高さ 32px、半透明白背景 + 角丸。世界観の中の看板ではなく、**システム UI として明示的に分離**。
- 左:
  - **「{N}日ぶり」バッジ**（任意。前回アプリ起動からの整数日が 1 以上のときだけ赤背景タグで表示）
  - 「きょうのすれちがい：N 人」
- 右: 進行インジケータ（例: 「3 / 5」または ●●●○○ 風）
- セッション中は常時表示。広場ビューに遷移したら消える。

> 「N 日ぶり」は **`app_settings.last_session_opened_at`** に保存した「前回開いた時刻」と現在時刻の差を 24h 単位で切り捨てて算出する。HomePage の起動シーケンスで **前回値を読み出してから現在時刻で上書き** することで、当該セッション内では一貫した値が表示される。3DS 時代の「数日溜めて開けた喜び」を再現するためのバッジで、0 日（同日内の再起動）では表示しない。

## 5. 仕様詳細

### 5.1 表示トリガー
アプリがフォアグラウンドになった直後（cold start / warm resume 両方）に、未読件数を判定。
**未読のうち `users_cache` にプロフィールが存在する（= [profile-sync.md](profile-sync.md) で fetch 済み）ものだけ** をキューに入れる。

```
on_foreground():
  # オフライン時はそもそも fetch が走っていないため、未 fetch のものは出ない
  ready_unread = db.fetch(
    encounter_logs JOIN users_cache
    where is_read = false
    order by encountered_at asc
    limit 20
  )
  if len(ready_unread) > 0:
    navigate_to(EncounterPopupScreen, queue = ready_unread)
  else:
    navigate_to(EncounterPlazaScreen)
```

未 fetch の `encounter_logs` は `is_read=false` のまま放置され、**プロフィールが取得できた後の起動回**で初めてポップアップに登場する。「半端な状態を見せない」ポリシー（[profile-sync.md](profile-sync.md) §5.5）。

### 5.2 表示順序
`encountered_at` 昇順（古い順）で表示。ユーザーが「時系列に追体験」する感覚を再現する。

### 5.3 シーケンス（1 人分）

```
1. 隊列の先頭が前に出てくる
   - 画面奥（隊列の位置）から手前（相手の定位置）へ歩いてくる（500ms）
   - その間、ユーザーのアバターは左で待機（呼吸 + まばたき）

2. 対面 + 待機
   - 相手が定位置に着き、両者向き合う
   - ストリップ UI のインジケータが進む

3. ハイタッチ判定
   - encounter_count >= 2: ハイタッチ動作 + 「TAP!」エフェクト
   - encounter_count == 1: 軽い会釈（お辞儀） + エフェクトなし

4. 吹き出し表示
   - システムプレフィックス（例: 「やっと 3 回目！」「はじめまして」）
   - 改行して本人のメッセージ
   - 右下に「タップで次へ」インジケータ

5. ユーザーのタップ
   - 相手は手を振って画面右へフレームアウト（300ms）
   - 同時に隊列の次の先頭が前に出てくる（1 と同じ）
```

### 5.4 ハイタッチ動作の詳細
- **タップで発火**: 対面状態で画面のどこかをタップ → ハイタッチアニメが起動。
- **アニメ内容**: 自分と相手が同時に内側の手を上にスイング（200ms）→ 中央で両手が触れる（50ms）→ 戻る（200ms）
- **タイミング**: 触れた瞬間に「TAP!」エフェクト（小さなテキスト + 短い拡縮）が中央上で 300ms フラッシュ
- **初回（encounter_count == 1）**: ハイタッチではなく **軽い会釈**（首を 15° 下げて戻る、400ms）。エフェクトなし。

### 5.5 システムプレフィックス文言
`encounter_count` に応じて自動付与する。

| 回数 | プレフィックス文言（仮） |
| --- | --- |
| 1 | 「はじめまして！」 |
| 2 | 「2 回目だね！」 |
| 3 | 「やっと 3 回目！」 |
| 4–9 | 「{N} 回目！」 |
| 10+ | 「もう {N} 回目！」 |

文言は将来チューニング可能なよう、**マニフェスト or 設定ファイル**に切り出す（実装で `i18n/encounter-prefix.json` 等に配置）。

### 5.6 1 セッションの上限と「会いにいく」フロー

#### 5.6.1 上限値
- **1 セッションあたり最大 20 人** を 1 つのキューとして表示する。
- DB から 20 件取得して順次表示し、最後まで進んだ時点でセッション終了画面を出す。

#### 5.6.2 セッション終了画面
- 残数 `remaining = unread_total - shown_in_session` を表示。
  - `remaining > 0` のとき: **「あと {remaining} 人に会いにいく」ボタン**を中央に配置。
  - `remaining == 0` のとき: **「広場へ入る」ボタン**を中央に配置。
- どちらのケースでも、画面下部に小さく「あとで広場で見る」リンクを置く（広場ビューへ即遷移、未表示分は次回起動に持ち越し）。

#### 5.6.3 「会いにいく」押下時の挙動
- DB から次の 20 件を取得して、新しいキューを開始。
- 上部ストリップ UI の総数表示が更新される（「今日のすれ違い：N → N+20 人」のような累計表示にする想定）。
- ストリップ UI のインジケータがリセットされて再開。

#### 5.6.4 押さずに離脱した場合
- 未表示の未読は `is_read = false` のまま残り、次回起動時の冒頭で再度ポップアップ対象になる。

### 5.7 広場への遷移演出（全員と挨拶し終わった後）
1. 「広場へ入る」ボタン押下、または 0 件離脱時。
2. これまで挨拶した全員が画面奥（ゲートの手前）に集合（500ms）。
3. ユーザーのアバターも合流して全員ゲートをくぐる動作に入る（800ms）。
4. **カメラがゲートに向かってパン**しながらクロスフェード（500ms）。
5. 広場ビュー（[encounter-plaza.md](encounter-plaza.md)）に到着。今日合流したアバター達はゲートから出てきて広場に散らばる。

### 5.8 既読化のタイミング
**対面シーンに入った瞬間**（隊列から前に出てきた直後）に `is_read = true` に更新する。
タップせずにアプリを閉じても、見た分は既読扱い。

### 5.9 エッジケース
- 表示中に新規エンカウントが発生 → 現在のキューには追加しない（次回起動時に表示）
- DB エラーで `is_read` 更新失敗 → エラーを UI に出さず、次回再表示される（冪等性で許容）
- 未読がちょうど 20 人 → 「会いにいく」ボタンは出さず「広場へ入る」のみ
- 「会いにいく」連打 → 取得後ボタンを 1 秒間 disable して二重起動を防止
- ハイタッチタップが極端に速い（吹き出し表示中の即タップ等）→ 入力を 200ms デバウンス

## 6. 受入基準
- [ ] 未読 1 件のとき、起動後に 1 度だけ対面シーンが出て、終了後に広場ビューに遷移する
- [ ] 未読 3 件のとき、隊列に 2 人並んだ状態で 1 人目との対面シーンが始まる
- [ ] 同じ相手と 2 回目のとき、ハイタッチアニメと「TAP!」エフェクトが発火する
- [ ] 初回（1 回目）のときはハイタッチではなく会釈で、エフェクトは出ない
- [ ] 吹き出しに「やっと 3 回目！」のようなシステムプレフィックスが本人メッセージの前に付く
- [ ] 上部ストリップに「今日のすれ違い：N 人」が常時表示される
- [ ] 前回起動から 24h 以上空いていれば、ストリップ左端に「{N}日ぶり」赤バッジが出る
- [ ] 同日内に再起動した場合は「N 日ぶり」バッジが出ない
- [ ] 未読 25 件のとき、20 人目終了で「あと 5 人に会いにいく」ボタンが出る
- [ ] 「会いにいく」を押すと、ストリップが更新されて残り 5 人を表示
- [ ] 全員終了後、カメラパン + ゲート通過のアニメで広場ビューに遷移する
- [ ] 「あとで広場で見る」を押すと、未表示分が次回起動で再提示される
- [ ] タップ連打で入力が壊れない（デバウンス）
- [ ] 60fps を著しく下回らない（中位スペック実機での実測）
